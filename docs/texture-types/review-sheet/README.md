# Texture review sheet

Every color of the live catalog, grouped by measured texture type (`node scripts/texture-review-sheet.mjs <outDir>`). For each color: the supplier photo on the left, a close-up of the 3D preview fabric on the right (a 40 x 64 in shade, lowered, normal size on a 1280 px desktop, not zoomed), marked **Generated** or **Photo**, with the colors where the type looks uncertain flagged. `index.json` has the same data (type, source, confidence, reason).
